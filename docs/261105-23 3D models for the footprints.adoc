= 3D models for the footprints
:toc:
:toclevels: 2

The 3D view reads the footprint on the board, not the schematic symbol.
The schematic was not edited. Each footprint already named an official
STEP file. Those files were not on this machine, and `KICAD10_3DMODEL_DIR`
was empty, so the view had nothing to load.


== What was fetched

Thirteen models, from the KiCad packages3D repository at tag 10.0.7.
They are in `libs/kicad-packages3D-10.0.7/`, about 4 MB. The set is the
DIP-14, DIP-16, DIP-28 and DIP-40 packages, both oscillators, the disc
and radial capacitors, the axial resistors, the push switch, the pin
headers, the DE9 shell, and the screw terminal.

The four mounting holes have no 3D model in the official footprint.
Nothing was invented for them.

The variable is set in the KiCad 10 configuration for this user:

`KICAD10_3DMODEL_DIR` =
`/home/falken/_/drv/v/261103-reto-comp-andrew-grok-kicad/libs/kicad-packages3D-10.0.7`

The board file still says `${KICAD10_3DMODEL_DIR}/...`, which is the
path the footprints were published with. The board editor was open, so
that file was not rewritten.


== Seeing them

Quit KiCad completely and open the project again. The variable is read
at startup. Then open the board and the 3D viewer. The parts should
have bodies. The mounting holes stay as holes.
